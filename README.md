# Purdue Club Finder
## Project Goal
Purdue Club Finder is a web application that helps Purdue students discover campus clubs and organizations based on their interests.
## MVP Features
- Browse Purdue clubs and organizations.
- Search clubs by name.
- Filter clubs by category and interests.
- View club descriptions, meeting times, and contact information.
## Future Plans
- Allow users to create accounts and log in.
- Allow users to save favorite clubs.
- Display upcoming club events.
- Send event reminders.
## Tech Stack
- Python: Main programming language.
- Flask: Web application framework.
- HTML, CSS, JavaScript: Frontend development.
- Pandas: Organizing and filtering club data.
- Bootstrap: Website styling.
- JSON: Storing club information.
- GitHub: Version control and project management.
