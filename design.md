# Purdue Club Finder – Design Document
## 1.1 Problem Statement
Finding clubs that match my interests, comparing meeting times, and keeping track of events can be difficult because information is spread across different websites and platforms. I want to make this process easier by putting club information, events, and meeting details in one organized place.
## 1.2 Project Idea
I am going to build a web application that allows Purdue students to browse, search, and filter campus clubs based on their interests. Users will be able to view club descriptions, meeting times, and contact information.
## 2.1 Eisenhower Matrix
### Do – MVP
- Display a list of Purdue clubs and organizations.
- Allow users to search and filter clubs by name, category, and interests.
- Show basic club information, including descriptions, meeting times, and contact information.
### Schedule – V2.0+
- Allow users to create personal accounts and log in.
- Let users save favorite clubs to a personalized list.
- Display upcoming club events and send event reminders.
### Delegate – Use a Library
- Use Bootstrap for website styling.
- Use a library to handle searching and filtering.
- Use a library to validate user input.
### Delete – Cut It
- Build a messaging system for communication between club members.
- Create a social media feed for every organization.
## 2.2 Tech Stack
- Language: Python, HTML, CSS, and JavaScript.
- Framework: Flask.
- Libraries: Pandas and Bootstrap.
- Data storage: JSON file.
- Data source: Publicly available Purdue BoilerLink information.
- Development tools: VS Code and GitHub.
